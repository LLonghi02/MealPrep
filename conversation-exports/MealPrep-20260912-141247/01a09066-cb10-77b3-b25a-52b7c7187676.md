## assistant — 09/11/2026 12:17:46

Una chiamata API serve a inviare o ricevere dati da un server. In un’app Expo puoi usare `fetch`, per esempio:

```js
async function caricaRicette() {
  try {
    const risposta = await fetch('https://api.example.com/ricette');

    if (!risposta.ok) {
      throw new Error(`Errore HTTP: ${risposta.status}`);
    }

    const ricette = await risposta.json();
    console.log(ricette);
  } catch (errore) {
    console.error('Chiamata API fallita:', errore);
  }
}
```

Sostituisci l’URL di esempio con quello della tua API. Questa è una richiesta **GET**, usata per leggere dati.

## assistant — 09/11/2026 12:19:20

La variabile nel `.env` si legge così:

```js
const apiKey = process.env.EXPO_PUBLIC_OPENAI_API_KEY;
```

La chiave serve per autenticare la chiamata a OpenAI, nell’header:

```js
headers: {
  'Content-Type': 'application/json',
  Authorization: `Bearer ${apiKey}`,
}
```

**Attenzione: `EXPO_PUBLIC_` rende la chiave visibile nell’app distribuita**, anche se la metti nel `.env`. [Documentazione Expo](https://docs.expo.dev/guides/environment-variables/)

Per l’app da pubblicare, conserva `OPENAI_API_KEY` sul backend: l’app chiama il tuo backend, che chiama OpenAI con la chiave privata. È quanto indica anche la [documentazione ufficiale OpenAI](https://developers.openai.com/api/reference/overview).

Food layers are Unicode emoji text in Figma. Several individual Figma PNG exports
were empty (179–200 bytes), so the app uses the original emoji characters.
Their appearance follows the platform emoji font.

OS status bar and Dynamic Island are device chrome and are not imitated in the UI.

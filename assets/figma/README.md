Option tiles use the original Unicode emoji text from Figma. Several individual
Figma PNG exports were empty (179–200 bytes); their appearance therefore follows
the platform emoji font. The landing animation uses the food PNG assets added
separately to the project. Only the five files listed above were downloaded as
exact Figma node exports during this implementation.

OS status bar and Dynamic Island are device chrome and are not imitated in the UI.
